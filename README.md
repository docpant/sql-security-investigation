# SQL Security Investigation

## Overview

This project demonstrates the use of SQL queries to investigate potential security issues involving employee login attempts and machine updates within an organization.

The project focuses on filtering data using SQL operators such as AND, OR, NOT, and LIKE to identify suspicious activity and retrieve relevant employee records.

## Objective

- Investigate suspicious login attempts
- Filter login activity by time and date
- Identify login attempts outside specific locations
- Retrieve employee records for security updates
- Apply SQL filtering techniques to security investigations

## SQL Concepts Used

- WHERE
- AND
- OR
- NOT
- LIKE
- Filtering dates and times

## Skills Demonstrated

- SQL query writing
- Security data analysis
- Login investigation
- Employee record filtering
- Pattern matching with LIKE
- Multi-condition filtering
